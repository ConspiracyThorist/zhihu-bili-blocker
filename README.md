# 知乎热榜屏蔽 B 站推荐

把「知乎热榜」当过滤字典：同步知乎标题，在 B 站首页推荐里做模糊匹配，命中就在**渲染前**摘掉——不是先显示再消失。

## 它做什么

- 屏蔽首页推荐里「照搬知乎问题」的搬运视频
- 只看标题，不看 UP 主、不看分区，所以换个号搬照样拦得住
- 全程本地运行：题库存在浏览器里，不上传任何数据

**覆盖范围：只处理 B 站首页推荐**，不含热门榜、搜索结果、播放页侧栏。

## 安装

### Chrome 扩展（推荐）

1. 下载 `zhihu-bili-blocker.zip` 并解压
2. 地址栏打开 `chrome://extensions`
3. 右上角打开「开发者模式」
4. 点「加载已解压的扩展程序」，选中解压出来的文件夹
5. 刷新 B 站首页

需要 Chrome 111 及以上。

### 油猴脚本

1. 安装 [Tampermonkey](https://www.tampermonkey.net/)
2. 打开 `zhihu-bili-blocker.user.js`，Tampermonkey 会自动提示安装
3. 刷新 B 站首页，右下角出现「知」按钮

两个都装也不冲突，隐藏是幂等的。

## 使用

点扩展图标（或油猴右下角「知」）打开面板：

| 控件 | 作用 |
|---|---|
| 总开关 | 关掉立刻生效，已隐藏的卡片马上恢复 |
| 相似度阈值 | 默认 0.72，往左更严（少误伤），往右更宽（多拦截） |
| 刷新热榜 | 手动拉一次；失败时显示上次成功时间 |
| 题库 | 当前字典条数（本地累积 + 远端同步） |
| 最近屏蔽 | 「B 站标题 ← 知乎标题 + 分数」，点「放行」加入白名单 |

### 阈值怎么调

| 现象 | 动作 |
|---|---|
| 明显是搬运的还在 | 调低到 0.68~0.70 |
| 误伤了正常视频 | 调高到 0.78~0.82，或直接点「放行」 |
| 只想杀原样照搬的 | 0.85 以上 |

改动立刻对后续加载生效，不用重装。

## 常见问题

**明明有搬运却没屏蔽？**
先看面板里的分数：如果那条视频的标题被大幅改写（不是照搬原题），字面匹配抓不到——这是当前算法的上限，需要语义匹配才能解决。如果是原样照搬却没拦，把阈值调到 0.68 试试。

**正常视频被误伤？**
点「放行」，它会进白名单，以后不再屏蔽。或者把阈值调到 0.8 以上。

**题库一直不涨？**
正常。知乎热榜每天只换 20~30 条，30 天窗口的稳态就是几百条。而且体检数据显示，其中只有约 15% 能在 B 站找到对应视频——不涨不代表坏了。

**面板显示「从未成功」或同步失败？**
知乎接口偶发 403，或远端题库源暂时不通。点「刷新热榜」看错误详情；扩展会保留上一份数据继续用，不会因此失效。

**B 站改版后彻底没效果？**
等我更新选择器。这类改动集中在 `src/core/dom.ts` 一处，通常改几行就能修好。

## 隐私

- 不收集、不上传任何数据。题库、配置、屏蔽记录全部存在浏览器本地
- 只访问两类域名：B 站首页接口、知乎热榜接口
- 扩展权限只有 `storage` 和 `alarms`，没有 `cookies`，读不到你的账号信息

## 已知限制

- 只覆盖首页推荐，不含热门、搜索、播放页侧栏
- 只比对标题，不看视频内容、UP 主、评论
- 中文短标题天然存在语义碰撞，做不到「绝对不误伤」，所以保留了阈值和白名单两道人肉兜底
- 大幅改写标题的搬运识别不了（约占总数的 11.7%）

## 原理

一句话：在页面解析推荐数据**之前**把命中项从 JSON 里摘掉，卡片从头到尾不会出现；接口没覆盖到的首屏卡片，再由 DOM 层兜底隐藏。
