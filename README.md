# 知乎热榜屏蔽 B 站推荐

把「知乎热榜」当过滤字典：同步知乎标题，在 B 站首页推荐里做模糊匹配，命中就在**渲染前**摘掉——不是先显示再消失。

## 它做什么

- 屏蔽首页推荐里「照搬知乎问题」的搬运视频
- 只看标题，不看 UP 主、不看分区，所以换个号搬照样拦得住
- 全程本地运行：题库存在浏览器里，不上传任何数据

**覆盖范围：只处理 B 站首页推荐**，不含热门榜、搜索结果、播放页侧栏。

## 安装

### Chrome 扩展（推荐）

1. 到 [Releases](https://github.com/ConspiracyThorist/zhihu-bili-blocker/releases/latest) 下载 `zhihu-bili-blocker.zip` 并解压
2. 地址栏打开 `chrome://extensions`
3. 右上角打开「开发者模式」
4. 点「加载已解压的扩展程序」，选中解压出来的文件夹
5. 刷新 B 站首页

需要 Chrome 111 及以上。

> 下载不动的话，把链接前面加上 `https://gh-proxy.com/` 走镜像，例如
> `https://gh-proxy.com/https://github.com/ConspiracyThorist/zhihu-bili-blocker/releases/download/v1.0.0/zhihu-bili-blocker.zip`。

### 油猴脚本

1. 安装 [Tampermonkey](https://www.tampermonkey.net/)
2. 点下面这个链接，Tampermonkey 会自动弹安装框：

   ```
   https://gh-proxy.com/https://raw.githubusercontent.com/ConspiracyThorist/zhihu-bili-blocker/main/zhihu-bili-blocker.user.js
   ```

3. 刷新 B 站首页，右下角出现浮窗

脚本只作为仓库里的文件维护，不走 Release。想自己看源码或改，直接打开 [zhihu-bili-blocker.user.js](zhihu-bili-blocker.user.js)。

两个都装也不冲突，隐藏是幂等的。

## 使用

### 页面上的浮窗

B 站页面右下角有个小胶囊，只显示两个数：**已拦截**（本次打开页面后拦了几条）和**累计**（历史总数）。鼠标移上去变实，点一下展开最近 5 条命中，可以就地「放行」。

### 弹窗

点扩展图标打开：

| 控件 | 作用 |
|---|---|
| 总开关 | 关掉立刻生效，已隐藏的卡片马上恢复 |
| 拦截强度 | 三档：保守 / 标准 / 激进，见下表 |
| 统计 | 最近记录、累计拦截、题库条目 |
| 刷新热榜 / 题库 | 手动拉一次；失败时显示上次成功时间（在「高级设置」里） |
| 最近拦截 | 「B 站标题 ← 知乎标题 + 分数」，点「放行」加入白名单 |

### 强度怎么选

| 档位 | 阈值 | 适合 |
|---|---|---|
| 保守 | 0.80 | 只想拦几乎原样照搬的，几乎不误伤 |
| 标准 | 0.72 | 默认，大多数搬运能拦住 |
| 激进 | 0.66 | 改写过的也尽量拦，误伤会变多 |

想精确调数值，展开「高级设置」里的滑杆——但大多数情况三档就够了。

## 常见问题

**明明有搬运却没屏蔽？**
先看面板里的分数：分数偏低说明 B 站那条标题和知乎原题差得比较远。可以把强度调到「激进」试试；如果它本来就是被改得面目全非的标题，那不是这套匹配能覆盖的场景。

**正常视频被误伤？**
点「放行」，它会进白名单，以后不再屏蔽。或者把阈值调到 0.8 以上。

**题库一直不涨？**
正常。知乎热榜每天只换 20~30 条，30 天窗口的稳态就是几百条。而且体检数据显示，其中只有约 15% 能在 B 站找到对应视频——不涨不代表坏了。

**面板显示「从未成功」或同步失败？**
知乎接口偶发 403，或远端题库源暂时不通。点「刷新热榜」看错误详情；扩展会保留上一份数据继续用，不会因此失效。

**B 站改版后彻底没效果？**
等我更新选择器。这类改动集中在 `src/core/dom.ts` 一处，通常改几行就能修好。

## 隐私

- 不收集、不上传任何数据。题库、配置、屏蔽记录全部存在浏览器本地
- 只访问两类域名：B 站首页接口、知乎热榜接口
- 扩展权限只有 `storage` 和 `alarms`，没有 `cookies`，读不到你的账号信息

## 已知限制

- 只覆盖首页推荐，不含热门、搜索、播放页侧栏
- 只比对标题，不看视频内容、UP 主、评论
- 中文短标题天然存在语义碰撞，做不到「绝对不误伤」，所以保留了阈值和白名单两道人肉兜底

## 原理

一句话：在页面解析推荐数据**之前**把命中项从 JSON 里摘掉，卡片从头到尾不会出现；接口没覆盖到的首屏卡片，再由 DOM 层兜底隐藏。
