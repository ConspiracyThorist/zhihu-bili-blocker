# 知乎热榜屏蔽 B 站推荐

把知乎热榜当成一张过滤网。先拿到热榜标题，再去 B 站首页推荐里比对，命中就在**渲染前**摘掉——不是先冒出来再消失。

## 📌 它管什么

- 首页推荐里那些「照搬知乎问题」的视频
- 只看标题。不看 UP 主，也不看分区，换个号搬照样拦得住
- 全程本地跑，题库存在浏览器里，不上传

只管 B 站首页推荐这一处。热门榜、搜索结果、播放页侧栏都不在范围内。

## 🧩 装哪个

扩展和油猴脚本二选一，装两个也不打架——隐藏是幂等的，重复命中不会有多余副作用。

### Chrome 扩展

1. 去 [Releases](https://github.com/ConspiracyThorist/zhihu-bili-blocker/releases/latest) 下 `zhihu-bili-blocker.zip`，解压
2. 地址栏敲 `chrome://extensions`
3. 右上角打开「开发者模式」
4. 点「加载已解压的扩展程序」，选中刚解压的文件夹
5. 刷新 B 站首页

要 Chrome 111 以上。

> 下载卡住的话，链接前面加 `https://gh-proxy.com/` 走镜像：
> `https://gh-proxy.com/https://github.com/ConspiracyThorist/zhihu-bili-blocker/releases/download/v1.0.0/zhihu-bili-blocker.zip`

### 油猴脚本

先装 [Tampermonkey](https://www.tampermonkey.net/)，然后点这个链接，它会自己弹安装框：

```
https://fastly.jsdelivr.net/gh/ConspiracyThorist/zhihu-bili-blocker@main/zhihu-bili-blocker.user.js
```

CDN 打不开就换这条：

```
https://gh-proxy.com/https://raw.githubusercontent.com/ConspiracyThorist/zhihu-bili-blocker/main/zhihu-bili-blocker.user.js
```

装完刷新首页，右下角会冒出一个小胶囊。

脚本不走 Release，只作为仓库文件维护。想看源码直接打开 [zhihu-bili-blocker.user.js](zhihu-bili-blocker.user.js)。

## 👀 怎么用

### 页面右下角的浮窗

一个不起眼的小胶囊，上面两个数：**已拦截**（这次打开页面拦了几条）和**累计**（历史总数）。

鼠标移上去才变实，点一下展开最近 5 条命中，觉得拦错了就地「放行」。这个浮窗可以拖着放，位置会记住。

### 弹窗

点浏览器工具栏的扩展图标：

| 控件 | 干什么的 |
|---|---|
| 总开关 | 关掉立刻生效，已经藏起来的卡片马上回来 |
| 拦截强度 | 保守 / 标准 / 激进，下面细说 |
| 统计 | 最近记录、累计拦截、题库条目 |
| 最近拦截 | 「B 站标题 ← 知乎标题 + 分数」，点「放行」进白名单 |

刷新热榜、远题库源这些不常用的，塞进了「高级设置」。

### 强度选哪档

| 档位 | 阈值 | 适合谁 |
|---|---|---|
| 保守 | 0.80 | 只拦几乎原样照搬的，基本不误伤 |
| 标准 | 0.72 | 默认。大多数搬运能拦住 |
| 激进 | 0.66 | 改写过的也尽量拦，代价是误伤变多 |

想抠数字，展开「高级设置」拖滑杆。不过多数时候三档就够了。

## ❓ 常见问题

**有搬运没拦下来？**

先看面板里的分数。分数低，说明那条 B 站标题和知乎原题差得远。可以试试调到「激进」；要是它本来就被改得面目全非，那就不是这套匹配能管的事了。

**误伤了正常视频？**

点「放行」，它会进白名单，以后不再拦。或者把强度调到保守。

**题库怎么一直不涨？**

正常的。知乎热榜每天只换 20~30 条，30 天窗口的稳态就是几百条。体检数据里只有约 15% 的条目能在 B 站找到对应视频——数字不动不代表坏了。

**面板显示「从未成功」或同步失败？**

多半是知乎接口偶发 403，或者远端题库源暂时不通。点「刷新热榜」看具体报错。扩展会留着上一份数据继续用，不会因此失效。

**B 站改版后彻底没效果？**

等我更新选择器。这类改动集中在 `src/core/dom.ts` 一个文件里，通常改几行就好。

## 🔒 隐私

不收集、不上传任何数据。题库、配置、屏蔽记录全在浏览器本地。

只访问两个域名：B 站首页接口、知乎热榜接口。扩展权限只有 `storage` 和 `alarms`，没有 `cookies`，读不到你的账号。

## 🚧 已知限制

- 只覆盖首页推荐，不含热门、搜索、播放页侧栏
- 只比对标题，不看视频内容、UP 主、评论
- 中文短标题天然会撞车，做不到「绝对不误伤」，所以留了阈值和白名单两道人肉兜底

## ⚙️ 原理

一句话：在页面解析推荐数据**之前**，把命中项从 JSON 里摘掉，卡片从头到尾不出现。接口没覆盖到的首屏卡片，再由 DOM 层补一刀。
